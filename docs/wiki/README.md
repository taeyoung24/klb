# Krown League Baseball (KLB) 위키

KLB(Krown League Baseball) 메인 위키이다.  
이 위키는 KLB의 역사, 리그 및 구단 구조, 주요 규칙, 연고지 정보 등 다양한 정보와 기록을 관리하는 공간이다.

## 위키 문서 작성 규칙

KLB 위키의 일관성과 명확성을 유지하기 위해 문서 작성 시 아래 지침을 준수한다.

1. **문체 지침 (`다/이다` 체 사용)**
   - 대화체나 경어체(`~입니다`, `~합니다`, `~해요`) 대신 정조한 평서체(`~이다`, `~한다`, `~인 듯하다`)를 사용한다.
   - 단호하고 객관적인 위키/백과사전식 톤앤매너를 유지한다.

2. **이모지 사용 지양**
   - 시각적 산만함을 줄이고 문서의 전문성을 높이기 위해 가급적 이모지(Emoji) 사용을 지양한다.
   - 구단 구분이나 리그 상징은 텍스트 및 코드/기호로 명확히 서술한다.

3. **링크 및 파일 경로**
   - 문서 간 연관 관계는 상대 경로 링크(`[문서명](./path/to/file.md)`)를 활용하여 프론트엔드 서빙 시 매끄럽게 연결되도록 한다.
   - 새 구단이나 인물/사건 작성 시 해당하는 카테고리 디렉터리 하위에 배치한다.

4. **메타적 어조 금지 (실체적 톤앤매너 유지)**
   - 개발자 시점이나 외부자 시점의 메타적 표현(`설정`, `가상`, `유니버스`, `시뮬레이션`, `서사`, `스토리`, `IP` 등) 사용을 엄격히 금지한다.
   - 실제 존재하는 리그, 구단, 인물, 지역의 객관적 기록 및 백과사전 본연의 어조(In-universe)를 유지한다.
